The challenge

Make the silliest browser game you can, mostly by chatting with an AI assistant. Think of a game where you herd confused pigeons, race office chairs, or defend a sandwich from seagulls. It can be as absurd as you like, but it must still be playable: someone should be able to pick it up, understand it in 30 seconds, and have a goal to chase.

The twist: use the basic, everyday version of whatever AI you have. The skill being tested is what you can make with the little you have.

Rules

    How to build it

    1. Pick a ridiculous idea

      Take a simple game everyone knows and give it one absurd twist. Some starters:

      • Whack-a-mole, but the moles are unread emails that multiply
      • A racing game where every car is a sofa
      • Catch falling pancakes on your head; stack them as high as you can
      • Pilot a pigeon through a city using only its very loud coo
      • Keep a houseplant alive while it develops strong opinions
    2. Copy the starter prompt into your AI

      Use the starter prompt below. Replace the last line with your idea, then send it. One or two sentences about your idea is plenty.

    3. Play the result

      In Claude: the game usually appears right in the chat, in a panel on the side. Click it to play.

      In ChatGPT, Gemini or Copilot: click "Preview" or open the "Canvas" if you see that option. Otherwise copy all of the code, paste it into a plain text editor (Notepad on Windows, TextEdit on Mac in plain-text mode), save it as game.html, and double-click the file. It opens in your browser.

    4. Iterate in plain language

      Tell the AI what to change, one thing at a time: "make the pigeon faster", "add a sound when I score". See tips for iterating.

    5. Save the final file

      Save the finished game as one .html file. Any name works.

      In Claude: use the download button on the game panel. Elsewhere: copy all the code into a plain text file and save it with .html at the end.

    6. Submit it on the website

      Sign in on the Submit page, fill in four details and choose your file. It's in the gallery about two minutes later. You get one game and up to two updates, so test it well before you submit. Submissions close at the deadline. See how to submit.

    Tips for iterating
    
        
    Ask for one change at a time and play it after every change. Good follow-ups to try:
    
        
    
          
    Make it sillier. Add three absurd surprises that happen at random.
    
          
    Add sound effects with the Web Audio API: a boing when I jump and a sad trombone when I lose.
    
          
    Make it get harder over time, so a round lasts about a minute.
    
          
    When I press the left arrow, the character goes right. Please fix that.
    
          
    Make it work on a phone: tap and drag should control it, and it should fit the screen.
    
          
    Add a title screen with the game name and a one-line "how to play".
    
        
    
        
    To fix a bug, describe what you see, not what you think the problem is. "The score stays at zero when I catch a pancake" works better than "fix the score variable".
    
      
    

      
    
        
    Troubleshooting
    
        
    
          The game is a blank white screen
          
    Tell the AI: "The game shows a blank screen when I open it. Please check for errors and send me the complete fixed file." Ask for the complete file, not just the changed part.
    
        
    
        
    
          The AI only sent part of the code, or it cut off halfway
          
    Say: "Your reply was cut off. Please send the complete HTML file again, from <!DOCTYPE html> to </html>." If it keeps happening, ask it to "make the code shorter and simpler".
    
        
    
        
    
          It tried to load an image, font or library from the internet
          
    Say: "Don't load anything from the internet. Draw everything with code, emoji or inline SVG, and put all the code in the one file." Games that load outside files may break on the gallery.
    
        
    
        
    
          It doesn't work on my phone
          
    Say: "It doesn't work on my phone. Add touch controls (tap and drag), make the game fit any screen size, and stop the page from scrolling while I play."
    
        
    
        
    
          The keyboard doesn't do anything
          
    Click on the game first so it has focus, then try the keys. If it still doesn't respond, tell the AI which key you pressed and what happened.
    
        
    
        
    
          The game works on my computer but not in the gallery
          
    The gallery runs every game in a safe sandbox, walled off from the site. It already handles the most common problem for you: saved high scores and settings work, but are forgotten when the page closes. If something else breaks, the preview on the Submit page shows the exact error, plus a message you can copy straight into your AI to fix it. If you're stuck, say: "This game doesn't work inside a sandboxed iframe. Please make it work without saving anything to the browser, and send me the complete file."
    
        
    
        
    
          I made it worse and want to go back
          
    Scroll up in the chat, copy an earlier version, and continue from there. Or say: "Go back to the version before the last change."

    Updating your game
    
          
    You enter one game, and you can't swap it for a different one later. After submitting, you get up to two updates to fix or improve it: go back to the Submit page, choose the new file, tick to confirm, and submit. Ratings and scores carry over to each new version. Once both updates are used, that version is final, so make every upload count.
    
        
    
        
    
          
    Submit early, then share it
    
          
    People's choice is decided by star ratings, and a game needs at least 5 ratings to qualify. The earlier you submit, the more time colleagues have to play it. After submitting, copy your game's link and share it in the RAY Connect chat.
    
        
    
        
    Can't get it to work? Message the organisers with your file and they'll add it for you.
