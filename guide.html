How to build it

  1. Pick a ridiculous idea

    Take a game everyone knows and add one absurd twist: whack-a-mole with unread emails, a race where every car is a sofa, stacking pancakes on your head.

  2. Paste the starter prompt into your AI

    Copy the prompt below into Claude, ChatGPT, Gemini or Copilot, and replace the last line with your idea.

  3. Play it

    Claude shows the game right in the chat. Elsewhere, use Preview or Canvas, or paste the code into a text file, save it as game.html, and double-click it.

  4. Iterate as much as you like

    Ask for one change at a time and play after each. Your AI chat is your canvas: experiment freely there. Nothing counts until you submit.

  5. Save and submit

    Download or save the finished game as one .html file, then send it in on the Submit page.

Tips

        

          
Make it sillier. Add three absurd surprises that happen at random.

          
Add sound effects: a boing when I jump and a sad trombone when I lose.

          
Make it get harder over time, so a round lasts about a minute.

          
Make it work on a phone: tap and drag to control it, and fit the screen.

        

        
To fix a bug, describe what you see ("the score stays at zero"), not what you think the code is doing.

      


      

        
Troubleshooting

        
Blank screen
Say: "The game shows a blank screen. Please fix it and send me the complete file."

        
The code is cut off
Say: "Your reply was cut off. Send the complete file again, from <!DOCTYPE html> to </html>." If it keeps happening, ask it to make the code shorter.

        
It loads images or code from the internet
Say: "Don't load anything from the internet. Draw everything with code or emoji, all in one file."

        
It doesn't work on my phone
Say: "Add touch controls, make it fit any screen, and stop the page scrolling while I play."

        
It works on my computer but not on the site
The preview on the Submit page shows the exact error, plus a message you can copy straight into your AI to fix it.
