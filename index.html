Welcome

Build something gloriously silly

You don't need to know how to code. You need a ridiculous idea, an AI assistant, and about an hour. Everything you need is in the guide, and there's a sample game showing the whole journey from first prompt to upload.

The brief

What you're building

One HTML file

Your whole game lives in a single file that opens in any browser. No installs, no servers, no extra files.

Built with basic AI

Use the free or standard version of Claude, ChatGPT, Gemini or Copilot. The challenge is what you can do with the little you have.

Silly, but playable

The sillier the better, as long as it works. It needs a goal, a score or a win/lose moment, and a restart button.
