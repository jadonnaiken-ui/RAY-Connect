    Part 2

    How it was uploaded

    Most entrants just send their file to the organisers (see how to submit). This is what happens next: how a game gets from a file on a laptop into the gallery, using only the GitHub website.

    1. Save the game as one file

      In Claude, the download button on the game panel saves the file. It was renamed to organisers-toaster-panic.html: lowercase, dashes, ending in .html.

    2. Open the games folder on GitHub

      On the repository's main page, click the games folder.

    3. Upload the file

      Click Add file → Upload files, then drag the .html file into the box. At the bottom, write a short note like "Add Toaster Panic" and click Commit changes.

    4. Add it to the gallery list

      Go back to the main page and click games.json, then the pencil icon (Edit this file). Paste the entry from the submission message just before the final ]. Put a comma after the } of the entry above it. Click Commit changes.

      [
  { …the entry that was already there… },   ← add this comma
  {
    "slug": "organisers-toaster-panic",
    "title": "Toaster Panic",
    "authors": ["The organisers"],
    "llm": "Claude",
    "file": "games/organisers-toaster-panic.html",
    "blurb": "Your toaster has become self-aware and is firing breakfast at the ceiling. Catch it.",
    "emoji": "🍞",
    "added": "2026-11-23",
    "award": null
  }
]
    5. Wait for the green tick

      Click the Actions tab. Within a minute you'll see a green tick (all good) or a red cross. Click a red cross and it tells you in plain English what's wrong, for example "Entry 3 (jadon-sofa-racer) is missing a blurb".

    6. Play it on the live site

      About two minutes later the game appears in the gallery. Refresh the page if you don't see it yet.
