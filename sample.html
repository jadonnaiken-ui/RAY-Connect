    How it was submitted

    From a file on a laptop to the gallery in about three minutes, without touching GitHub.

    1. Save the game as one file

      In Claude, the download button on the game panel saves the .html file. In other assistants, copy all the code into a text file and save it ending in .html.

    2. Open the Submit page and sign in

      Click Submit in the menu, then Sign in with Google using a work account.

    3. Fill in four details

      Name, title ("Toaster Panic"), main AI ("Claude"), and a one-liner: "Your toaster has become self-aware and is firing breakfast at the ceiling. Catch it." Plus an emoji: 🍞.

    4. Choose the file and check the preview

      After picking the file, a preview appears right on the page. A quick play confirms it works in the gallery's sandbox.

    5. Submit, then wait about two minutes

      The website publishes the game automatically. A couple of minutes later it's in the gallery, ready to play and rate.

    6. Two updates, then it's final

      Asked the AI for a fix? Back on the Submit page, choose the new file, tick "Yes, use an update", and submit. Everyone gets two updates, so it pays to test properly first.
